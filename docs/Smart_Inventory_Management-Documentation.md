## 1. Project summary

Smart Inventory Management is a React web application (Vite) for tracking products, alerts for low stock, transactions, users, and generating reports (CSV/PDF). The codebase is primarily JavaScript with a component-driven UI, services layer for API calls, and pages for dashboard, alerts, reports, products, and authentication.

## 4. Key techniques & patterns used

- Component-driven UI with a shared Layout component that handles navigation, idle logout, and theme toggle.
- Services layer: abstraction over API endpoints (AuthService, ProductService, etc.) to centralize HTTP calls, error handling, and token management.
- Authentication flow: Login and Register components use AuthService to authenticate and persist user session (likely via localStorage/sessionStorage).
- Protected/admin flows: Dashboard checks user roles to show admin-only actions.
- Real-time/near-real-time monitoring: Alerts page computes ratios (currentStock / minimumStock) to categorize alerts and display counts.
- Reporting: UI page provides CSV / PDF downloads for products and transactions via ReportService.
- Idle timeout handling: Layout implements IDLE_TIMEOUT_MS (30 minutes) to auto-logout users after inactivity.
- Pagination / statistics: Dashboard aggregates stats from multiple services with Promise.all for parallel fetches.
- UX: Loading states, graceful fallbacks, and descriptive empty-state UIs (e.g. when no alerts present).
- Path aliasing: Vite config maps '@' to ./src for cleaner imports.
- Linting: ESLint configuration focusing on React hooks and refresh plugin.
